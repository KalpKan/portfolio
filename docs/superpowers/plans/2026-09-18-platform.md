# T1.1 Platform (Supabase Project B + basketball as `hoops` schema) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Restore Supabase project `yzppfufqaekgaxcrsqxp` as Project B "platform", move the basketball backend into a `hoops` schema there, wire the Vercel dashboard to it so it renders real rows, and put a DB-touching `health` Edge Function under an UptimeRobot keep-alive.

**Architecture:** Project B is the shared Supabase home for every non-promptflip app, one Postgres schema per app (`docs/hosting-plan.md` §6 "Database plan"). Basketball's tables/views move from `public` to `hoops`; the schema is exposed through PostgREST; the Edge Function `hoops-ingest-shot` writes with `db: { schema: "hoops" }`; the dashboard reads with the service-role client scoped the same way. A `health` Edge Function runs `select 1` through PostgREST so a 5-minute UptimeRobot ping counts as database activity.

**Tech Stack:** Supabase Management API (`api.supabase.com/v1`), Supabase CLI via `npx supabase@2` (link, db push, functions deploy, gen types), Vercel CLI (`npx vercel@latest`), Next.js 15 dashboard (pnpm workspace), posthog-js, UptimeRobot v3 API.

**Spec:** `docs/hosting-plan.md` §6 (Database plan, Migration of basketball), §7 row 4, Appendix T1.1; the T1.1 brief in the orchestrator message.

### Task 5: Edge Functions `hoops-ingest-shot` and `health`

**Files:**
- Move: `supabase/functions/ingest-shot/` -> `supabase/functions/hoops-ingest-shot/` (`createClient(url, key, { db: { schema: "hoops" } })`)
- Create: `supabase/functions/health/index.ts`:
  ```ts
  import { createClient } from "npm:@supabase/supabase-js@2";
  Deno.serve(async () => {
    const url = Deno.env.get("SUPABASE_URL"); const key = Deno.env.get("SUPABASE_SERVICE_ROLE_KEY");
    if (!url || !key) return Response.json({ ok: false, db: "unconfigured" }, { status: 500 });
    const supabase = createClient(url, key, { db: { schema: "hoops" } });
    const { error } = await supabase.rpc("health_select_one");
    if (error) return Response.json({ ok: false, db: error.message }, { status: 500, headers: { "cache-control": "no-store" } });
    return Response.json({ ok: true, db: "ok" }, { headers: { "cache-control": "no-store" } });
  });
  ```
  plus migration `0005_health_function.sql`: `create or replace function hoops.health_select_one() returns integer language sql stable as $$ select 1 $$;` (so the ping is a real DB round-trip) with grant execute to anon, service_role.
- Create: `supabase/functions/health/deno.json` no-op; `config.toml` `[functions.health] verify_jwt = false` so UptimeRobot can call it without a bearer token.
