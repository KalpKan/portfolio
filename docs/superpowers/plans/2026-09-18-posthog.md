# T0.5 PostHog Analytics Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One PostHog Cloud project ("Kalp portfolio", $0 forever) receiving cookieless, ad-blocker-resistant analytics from the hub via a `/ingest` reverse proxy, with one dashboard Kalp can bookmark and a written contract every later app follows.

**Architecture:** `posthog-js` is initialised once in a client provider (`components/PostHogProvider.tsx`) using `lib/posthog.ts`; `next.config.ts` rewrites `/ingest/*` to PostHog's US ingest hosts so requests stay first-party; the project rows in `components/Board.tsx` fire `project_card_clicked {slug,type}`. Project settings, insights and the dashboard are created through the PostHog REST API with the operator key; billing limits are set in the dashboard by browser because the billing API refuses personal keys.

**Tech Stack:** Next.js 16 (App Router), posthog-js, vitest + jsdom, PostHog REST API (`https://us.posthog.com/api`), Vercel CLI, claude-in-chrome.

**Spec:** `docs/hosting-plan.md` §6 "Analytics layer", §10 item 9; `docs/superpowers/plans/2026-09-18-phase-0-foundation.md` "Task T0.5".

## Global Constraints

- Spend $0. Never attach a card. Never subscribe to a paid PostHog plan.
- `POSTHOG_PERSONAL_API_KEY` (phx_, all-access) lives only in `~/.config/portfolio-ops/secrets.env`; never print, never commit.
- `phc_` project token is public by design and goes in `NEXT_PUBLIC_POSTHOG_KEY` on Vercel; it may be recorded in `docs/analytics.md` but never in a `.env` file in git.
- Cookieless: `persistence: 'memory'`. Session replay masks all inputs. Autocapture on.
- Event names: snake_case past-tense verbs (`project_card_clicked`).
- Do not touch DNS; another agent owns it.
- Reality found at plan time: the org "KalpKan" already has exactly one project (`616829`, "Default project", created 2026-09-18). PostHog Free allows one project, so **rename** it rather than create a second.
