# Pushup Form Tracker (browser) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship https://pushups.kalpkan.com, a static Vite app that counts good-form pushups from the webcam (or a bundled demo clip) entirely in the browser, and purge the old Python repo's 230 MB of data files via a PR.

**Architecture:** MediaPipe `@mediapipe/tasks-vision` PoseLandmarker (lite model + WASM self-hosted) → 12-landmark feature vector → baked StandardScaler → TF.js port of `pushup_model_augmented.h5` → verbatim port of the Python shoulder-height rep state machine → canvas overlay. Everything ML loads lazily on the first click so the initial page stays light. Unit tests compare the TS pipeline with Python-generated fixtures.

**Tech Stack:** Vite 8 + TypeScript 6, vitest 5, `@mediapipe/tasks-vision`, `@tensorflow/tfjs`, `posthog-js`; Python 3.10 venv (`tensorflow 2.15`, `tensorflowjs`, `mediapipe 0.10.14`, `scikit-learn`, `imageio-ffmpeg`) for one-off exports only.

**Spec:** `docs/superpowers/specs/2026-09-18-pushups-design.md`

## Global Constraints

- $0: Vercel Hobby, no card, no upgrades. Non-commercial.
- No secrets in the repo; PostHog public token only via `VITE_PUBLIC_POSTHOG_KEY` on Vercel.
- No network calls after load except same-origin files and `/ingest/*`.
